Modo: Exploración Histórica BASE DEL MODELO

Consulta los datos de predicción calculados por los modelos XGBoost / CatBoost sobre las 70,751 secciones electorales del padrón 2024. Estos valores representan la probabilidad de abstención estimada para cada sección a partir del historial electoral 2009-2021 y variables sociodemográficas. No son resultados observados - son predicciones del modelo.

Las predicciones del modelo están calibradas sobre 2024.

Modo Predicción / Proyección Electoral

Generador de Proyecciones para Elecciones Futuras

Este módulo aplica los modelos ML (XGBoost / CatBoost) calibrados sobre el ciclo 2024 para estimar el riesgo de abstención en procesos electorales futuros. Los valores mostrados son proyecciones estadísticas, no datos observados.

Elecciones intermedias: históricamente ~4% más de abstención que presidenciales.

Aplica el factor de ajuste prospectivo por tipo de proceso electoral y reclasifica el riesgo de las 70,751 secciones. El mapa superior se actualiza de inmediato.

¿Cómo genera la predicción?

Explicación del modelo

El sistema analiza el historial electoral y variables territoriales para estimar el riesgo de abstención futura. La salida es una proyección estadística, no un dato observado.
